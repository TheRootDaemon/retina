# Retina

**_Retina_** is an attempt to give the **_Coding Agents_** a pair of eyes.

## Why Retina?

Sure, there are tools like [tavily](https://www.tavily.com) and it's a very mature one at that.

But why should I bother with api keys and usage limits when I can run this on my own machine?

So instead of relying on the external factors, **_Retina_** aims to make use of your own machine
to give your coding agents a pair of eyes ie., a **_Browser_**.

# History

**_Retina_** had ancestors.

It all started as a _down detector_ then a _SSH Credential Wrapper_, then finally **_Retina_**.

I hope this doesn't end up being useful only to me :)
