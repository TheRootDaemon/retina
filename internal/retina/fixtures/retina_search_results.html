Retina — A Pair of Eyes for AI Agents
Retina is an attempt to give the Coding Agents a pair of eyes.
Retina's Ancestors
Retina had ancestors. This thing was supposed to be a down detector, then a SSH Credential Wrapper, then finally Retina. I hope this doesn't end up being useful only to me :)
Why Retina?
Sure, there are tools like tavily and it's a very mature one at that. But why should I bother with api keys and usage limits when I can run this on my own machine? So instead of relying on the external factors, Retina aims to make use of your own machine to give your coding agents a pair of eyes ie., a Browser.
